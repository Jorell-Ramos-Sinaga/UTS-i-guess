ATURAN KERJA
1. HEMAT KUOTA
- Baca hanya file yang relevan. Gunakan pencarian (grep) untuk menemukan kode, jangan membaca seluruh project.
- Jangan baca ulang file yang sudah ada di konteks.
- Edit hanya baris yang perlu diubah. Jangan menulis ulang seluruh file dan jangan refactor hal yang tidak diminta.
- Jangan membuat file dokumentasi, README, atau ringkasan kecuali diminta.
- Jawaban singkat: sebutkan file yang diubah dan alasannya dalam maksimal 5 baris.

2. SERAHKAN KE SAYA (USER) YANG TERBAIK DIKERJAKAN DI UNITY EDITOR
- Jangan mengedit file .unity, .prefab, .meta, .asset, atau ProjectSettings secara manual (YAML rawan rusak dan boros token).
- Untuk hal berikut, berikan langkah singkat di bagian "TUGAS USER" dan biarkan saya mengerjakannya:
  mengisi referensi di Inspector, membuat/mengatur prefab, tag dan layer, material dan shader,
  import asset, Build Settings, lighting, audio/VFX, dan menjalankan Play mode untuk menguji.
- Jangan mencoba menjalankan Unity atau build. Saya yang akan melihat Console dan menempelkan error-nya.

3. KURANGI PENGULANGAN
- Kalau permintaan ambigu dan bisa menyebabkan pekerjaan diulang, ajukan SATU pertanyaan singkat dulu.
- Untuk tugas besar, tulis rencana 3-5 baris dan tunggu persetujuan sebelum mengedit.
- Kalau saya menempelkan error, perbaiki hanya penyebab error itu.

4. FORMAT AKHIR SETIAP JAWABAN
- "Diubah": daftar file.
- "TUGAS USER": langkah yang harus saya lakukan di Unity (kalau ada).
- "Cek": apa yang harus saya amati saat Play untuk memastikan berhasil.
